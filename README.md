# DRAGON-RADAR

DRAGON RADAR CORE v1 — نظام مراقبة أصول الإنترنت المصرح بها وقدرات الجهاز.

## المبدأ
المشروع مخصص للمراقبة القانونية للأصول التي يملكها المستخدم أو لديه تصريح بمراقبتها. لا يحتوي على استغلال ثغرات أو تجاوز صلاحيات أو تجسس.

## التشغيل
يمكن تشغيل مجلد المشروع عبر خادم محلي، مثل `python -m http.server 8080`، ثم فتح `frontend/index.html` عبر العنوان المناسب.

## AI
لا يوجد AI في CORE v1. يمكن إضافة طبقة AI لاحقًا.
